# Paradise Nursery - E-Plant Shopping

This is a React-based shopping cart application for an online plant shop built for the final project.

## Features
* Landing page with welcoming background and navigation
* Dynamic product listing categorized by plant types
* Redux state management for shopping cart operations
* Add to cart, adjust quantities, calculate subtotals, and remove items
* Dynamic cart counter in the navigation bar

## Technologies Used
* React
* React Router DOM
* Redux Toolkit
* CSS3

## Installation and Setup Instructions
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm start` to run the app in development mode
4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
